### 📊 Project Description
This is a Python dashboard built with Streamlit to help Malaysian businesses plan their USD payments.

It uses Machine Learning to predict if the USD/MYR exchange rate will go UP or DOWN in the next 30 days. This helps users decide if they should "Pay Now" or "Wait" to save money.

### 🚀 How to Run the App

1. **Install the required libraries:**
   pip install -r requirements.txt

2. **Get the latest data:**
   python get_data.py

3. **Run the Dashboard:**
   streamlit run app.py

---
**Files in this repository:**
* `app.py`: The main dashboard code.
* `get_data.py`: Script to download data from Bank Negara Malaysia.
* `historical_usd_myr.csv`: The dataset used for prediction.
* `requirements.txt`: List of libraries needed.
